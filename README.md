# together

Watch a video in sync with friends. Peer-to-peer, no server, no accounts.

This repository only holds release binaries. Grab the [latest release](https://github.com/temporaryfix/together-releases/releases/latest), or install with one line.

**macOS and Linux:**

```sh
curl -fsSL https://github.com/temporaryfix/together-releases/releases/latest/download/install.sh | sh
```

**Windows**, in PowerShell:

```powershell
irm https://github.com/temporaryfix/together-releases/releases/latest/download/install.ps1 | iex
```

Then start a room with `together movie.mp4` and send the invite it prints to your friends.
They run `together <invite>` and stream your copy, or add their own copy of the file to the end.
